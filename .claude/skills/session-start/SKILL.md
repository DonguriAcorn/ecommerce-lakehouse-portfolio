# セッションの始め方

1. `git status -sb` を実行し、未コミットのファイルと、未 push のコミットがあるかを確かめる。あれば、要約の前に伝える。
2. docs/tasks.md の「現在の状態」と、「← 今ここ」の付いたタスク(その下の小さなタスクも)を読む。
3. 次の形で、3行で要約する。
   - 済んだこと:
   - いまのタスク:
   - 次の1手:
4. 「次の1手」を、最初のステップとして1つだけ提案し、返事を待つ。
5. 承認があるまで、ファイルの変更や、読むだけでないコマンドを実行しない。
